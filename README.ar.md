# روبوت مبيعات VPN-UI عبر تيليجرام

روبوت تيليجرام للبيع وإدارة الحسابات، يعمل مع نسخة واحدة متصلة من لوحة VPN-UI عبر واجهة HTTP API، ويخزن بياناته المحلية في SQLite.

## الميزات

- قائمة للعملاء باللغة الفارسية ولوحة إدارة رسومية داخل تيليجرام.
- باقات ثابتة وخدمات محسوبة حسب الحجم (الحجم × سعر الجيجابايت شهرياً × عدد الأشهر).
- اختيار العميل لاسم المستخدم مع منع التكرار في الروبوت واللوحة.
- الدفع بالبطاقة إلى البطاقة، وإرسال صورة الإيصال، ثم موافقة المدير أو رفضه يدوياً.
- إنشاء حسابات VLESS وL2TP، وقراءة مفتاح PSK الخاص بـ L2TP/IPsec من إعدادات Inbound المحدد.
- استلام ملفات تعريف OpenVPN TCP/UDP وإرسالها عند توفر نقطة النهاية المطلوبة في إصدار اللوحة المتصل.
- تجربة VLESS لمرة واحدة بسعة 1 جيجابايت ولمدة 24 ساعة، يحدد المدير Inbound الخاص بها.
- عرض الحسابات وتجديدها وفحص الاستهلاك وتفعيلها أو تعطيلها أو حذفها، ورسائل الدعم والإعلانات ونسخ قاعدة البيانات احتياطياً.
- تشفير بيانات اعتماد الحسابات المخزنة باستخدام Fernet.

يدير الروبوت Inbound المتوافقة داخل لوحة VPN-UI واحدة متصلة؛ ولا يدير عدة لوحات. إنشاء حسابات WireGuard وOpenConnect غير مدعوم في هذا الإصدار.

## المتطلبات

- Ubuntu 22.04 أو 24.04
- Python 3.10 أو أحدث
- رمز بوت تيليجرام ومعرّفات المدير الرقمية
- حساب في لوحة VPN-UI يمكنه الوصول إليها وإدارة Inbound والعملاء
- عنوان IP أو نطاق VPN عام يمكن للعملاء الوصول إليه

## التثبيت

```bash
git clone https://github.com/amiinnoriizade-lang/aminui-sales-bot.git
cd aminui-sales-bot
sudo bash install.sh
```

سيطلب برنامج التثبيت رمز تيليجرام ومعرّفات المدير وبيانات الاتصال بلوحة VPN-UI. لا تظهر الأسرار أثناء إدخالها، وتحفظ في ملف `.env` بصلاحيات مقيدة. يُنشأ مفتاح التشفير مرة واحدة؛ احتفظ بنسخة احتياطية آمنة منه ولا تستبدله بعد تخزين بيانات الحسابات.

المسار الافتراضي للتثبيت هو `/opt/vpnui-sales-bot`، واسم خدمة systemd هو `vpnui-sales-bot.service`. يمكن تغيير مجلد التطبيق باستخدام `APP_DIR`.

تشغيل الخدمة ومراجعتها:

```bash
sudo systemctl start vpnui-sales-bot
sudo systemctl status vpnui-sales-bot --no-pager
sudo journalctl -u vpnui-sales-bot -f
```

## الإعداد الأول داخل تيليجرام

1. أرسل `/start` من حساب المدير.
2. افتح **مدیریت ربات** (إدارة الروبوت).
3. تحقق من اتصال اللوحة وراجع Inbound المتاحة.
4. اختر Inbound نشطاً من نوع VLESS لحساب التجربة المجاني.
5. أنشئ الباقات الثابتة أو الباقات المحسوبة حسب الحجم، وحدد Inbound لكل باقة.
6. اضبط رقم البطاقة واسم صاحبها وتعليمات الدفع.
7. نفّذ الأمر `/paneltest` للتحقق من إمكانية قراءة API اللوحة.

إنشاء الحسابات يضيف عملاء حقيقيين إلى اللوحة المتصلة. اختبر إصدار VPN-UI وInbound المحدد بحساب تجريبي قبل تقديم الخدمة للعملاء.

## الأمان

- لا ترفع ملف `.env` أو نسخه الاحتياطية أو قواعد SQLite أو بيانات دخول اللوحة إلى GitHub.
- احتفظ بنسخة آمنة من `.env` وقاعدة البيانات معاً.
- احتفظ بـ `APP_ENCRYPTION_KEY`؛ فبدونه لا يمكن فك تشفير بيانات الاعتماد.
- التحقق من شهادات TLS إلزامي.
- شغّل نسخة polling واحدة فقط لكل رمز بوت تيليجرام لتجنب تعارضات polling.
