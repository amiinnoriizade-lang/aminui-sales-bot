# Telegram-бот продаж VPN-UI

Telegram-бот для продаж и управления учетными записями, работающий с одним подключенным экземпляром панели VPN-UI через HTTP API. Локальные данные приложения хранятся в SQLite.

## Возможности

- Клиентское меню на персидском языке и графическое меню администратора в Telegram.
- Фиксированные тарифы и тарифы по объёму (объём × цена за ГБ в месяц × количество месяцев).
- Выбор имени пользователя клиентом с проверкой повторов в боте и панели.
- Оплата переводом на карту: отправка чека и ручное подтверждение или отклонение администратором.
- Создание учетных записей VLESS и L2TP. PSK для L2TP/IPsec считывается из настроек выбранного inbound.
- Получение и отправка профилей OpenVPN TCP/UDP, если подключенная версия панели поддерживает нужный endpoint.
- Одноразовый пробный VLESS-доступ на 1 ГБ сроком на 24 часа; inbound выбирает администратор.
- Просмотр и продление учетных записей, проверка трафика, включение, отключение и удаление аккаунтов, поддержка, рассылки и резервное копирование базы данных.
- Шифрование сохраненных учетных данных с помощью Fernet.

Бот управляет совместимыми inbound в одном подключенном экземпляре VPN-UI и не является системой управления несколькими панелями. Создание учетных записей WireGuard и OpenConnect в этой версии не реализовано.

## Требования

- Ubuntu 22.04 или 24.04
- Python 3.10+
- Токен Telegram-бота и числовые ID администраторов Telegram
- Доступная панель VPN-UI с правами управления inbound и клиентами
- Публичный IP-адрес или домен VPN, доступный клиентам

## Установка

```bash
git clone https://github.com/amiinnoriizade-lang/aminui-sales-bot.git
cd aminui-sales-bot
sudo bash install.sh
```

Установщик запросит токен Telegram, ID администраторов и параметры подключения к VPN-UI. Секреты вводятся без отображения и сохраняются в файле `.env` с ограниченными правами доступа. Ключ шифрования создается один раз. Сохраните его резервную копию и не заменяйте после сохранения учетных данных.

Путь установки по умолчанию: `/opt/vpnui-sales-bot`. Служба systemd: `vpnui-sales-bot.service`. Каталог приложения можно изменить через `APP_DIR`.

Запуск и проверка службы:

```bash
sudo systemctl start vpnui-sales-bot
sudo systemctl status vpnui-sales-bot --no-pager
sudo journalctl -u vpnui-sales-bot -f
```

## Первоначальная настройка в Telegram

1. Отправьте `/start` из учетной записи администратора.
2. Откройте **مدیریت ربات** (управление ботом).
3. Проверьте подключение к панели и список доступных inbound.
4. Выберите активный inbound VLESS для бесплатного пробного аккаунта.
5. Создайте фиксированные тарифы или тарифы по объёму и назначьте inbound каждому тарифу.
6. Настройте номер карты, имя владельца карты и инструкции по оплате.
7. Выполните `/paneltest`, чтобы проверить доступ к API панели.

Создание аккаунта добавляет реального клиента в подключенную панель. Перед продажей проверьте конкретную версию VPN-UI и выбранный inbound на тестовом аккаунте.

## Безопасность

- Не публикуйте `.env`, его резервные копии, базы SQLite и учетные данные панели в GitHub.
- Храните резервные копии `.env` и базы данных вместе в защищенном месте.
- Сохраните `APP_ENCRYPTION_KEY`: без него нельзя расшифровать учетные данные.
- Проверка TLS-сертификатов обязательна.
- Для одного токена Telegram-бота запускайте только один экземпляр polling, чтобы избежать конфликтов.
