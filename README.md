## امکانات ربات

- منوی مشتری فارسی و منوی گرافیکی مدیریت در تلگرام.
- پلن‌های ثابت و پلن‌های حجمی با محاسبه قیمت بر اساس حجم × قیمت هر گیگ در ماه × تعداد ماه.
- انتخاب نام کاربری دلخواه توسط مشتری و بررسی تکراری نبودن آن در ربات و پنل.
- پرداخت کارت‌به‌کارت: ارسال تصویر رسید و تأیید یا رد دستی توسط مدیر، سپس ساخت اکانت.
- ساخت اکانت VLESS و L2TP؛ مقدار PSK مربوط به L2TP/IPsec از تنظیمات Inbound انتخاب‌شده خوانده می‌شود.
- دریافت و ارسال پروفایل OpenVPN TCP/UDP، در صورتی که نسخه پنل متصل، endpoint موردنیاز را ارائه کند.
- اکانت تست رایگان VLESS، یک‌بار برای هر کاربر، با حجم ۱ گیگابایت و اعتبار ۲۴ ساعت؛ Inbound تست را مدیر انتخاب می‌کند.
- فهرست اکانت‌ها، تمدید، مشاهده مصرف ترافیک، فعال/غیرفعال/حذف کردن اکانت توسط مدیر.
- پیام‌های پشتیبانی، ارسال پیام همگانی و پشتیبان‌گیری از دیتابیس.
- رمزنگاری اطلاعات ورود ذخیره‌شده با Fernet.

ربات می‌تواند Inboundهای سازگار را در همان یک نمونه پنل VPN-UI انتخاب کند؛ سامانه مدیریت چند پنل نیست. ساخت اکانت WireGuard و OpenConnect در این نسخه پیاده‌سازی نشده است.

## پنل اصلی VPN-UI

این ربات به پنل **VPN-UI** متصل می‌شود و خودش جایگزین پنل VPN نیست. ابتدا باید پنل VPN-UI را روی سرور VPN نصب و راه‌اندازی کنید؛ سپس آدرس پنل و اطلاعات ورود آن را هنگام نصب ربات وارد کنید.

- **مخزن رسمی VPN-UI:** https://github.com/Sir-MmD/vpn-ui
- **راهنمای فارسی پنل:** https://github.com/Sir-MmD/vpn-ui/blob/main/README_FA.md
- **کانال پروژه:** https://t.me/vpn_ui_project

### دستور نصب پنل VPN-UI

روی سرور Ubuntu یا Debian، دستور رسمی زیر را با دسترسی root اجرا کنید:

```bash
curl -Ls https://raw.githubusercontent.com/Sir-MmD/vpn-ui/refs/heads/main/deploy.sh | sudo bash
```

پس از نصب پنل، آدرس ورود، پورت، مسیر (Base Path)، نام کاربری و رمز عبور پنل را یادداشت کنید. این اطلاعات را در مرحله نصب ربات وارد خواهید کرد. آدرس پنل مدیریتی با IP یا دامنه عمومی اتصال کاربران VPN یکی نیست؛ این دو مقدار را با هم اشتباه نگیرید.

- Ubuntu 22.04 یا 24.04
- Python نسخه 3.10 یا بالاتر

- IP یا دامنه عمومی VPN که کاربران بتوانند به آن متصل شوند

## نصب

دستورات زیر را روی سرور اجرا کنید:

```bash
git clone https://github.com/amiinnoriizade-lang/aminui-sales-bot.git
cd aminui-sales-bot
sudo bash install.sh
```

نصاب اطلاعات زیر را می‌پرسد و پس از ذخیره تنظیمات، سرویس را خودکار اجرا می‌کند. اگر سرویس بالا نیاید، نصب با نمایش گزارش خطا متوقف می‌شود:
1. توکن ربات تلگرام
2. شناسه عددی مدیر (برای چند مدیر، شناسه‌ها را با کاما جدا کنید)
3. آدرس پنل VPN-UI همراه پورت و Base Path
4. نام کاربری و رمز عبور پنل
5. IP یا دامنه عمومی سرور VPN (اختیاری)

اطلاعات محرمانه هنگام ورود نمایش داده نمی‌شوند و در فایل `.env` با مجوز محدود ذخیره می‌شوند. کلید رمزنگاری فقط یک‌بار ساخته می‌شود؛ از آن نسخه پشتیبان امن نگه دارید و پس از ذخیره شدن اطلاعات حساب‌ها آن را تغییر ندهید.

مسیر پیش‌فرض نصب `/opt/aminui-sales-bot` است و سرویس systemd با نام `aminui-sales-bot.service` ساخته می‌شود. مسیر نصب را می‌توان با متغیر `APP_DIR` تغییر داد.

### اجرای سرویس و مشاهده گزارش

```bash
sudo systemctl start aminui-sales-bot
sudo systemctl status aminui-sales-bot --no-pager
sudo journalctl -u aminui-sales-bot -f
```

## راه‌اندازی اولیه از داخل تلگرام

1. با حساب مدیر به ربات پیام `/start` بدهید.
2. وارد بخش **مدیریت ربات** شوید.
3. گزینه **مشاهده Inboundهای پنل** را باز کنید و اتصال پنل را بررسی کنید.
4. برای اکانت تست رایگان، از بخش **Inbound اکانت تست** یک Inbound فعال VLESS انتخاب کنید.
5. پلن‌های ثابت یا حجمی را بسازید و Inbound موردنظر هر پلن را انتخاب کنید.
6. شماره کارت، نام صاحب کارت و توضیحات پرداخت را در بخش **تنظیمات پرداخت** وارد کنید.
7. دستور `/paneltest` را برای بررسی دسترسی خواندن API پنل اجرا کنید.

ساخت اکانت، کلاینت واقعی در پنل ایجاد می‌کند. پیش از ارائه سرویس به مشتری، نسخه دقیق VPN-UI و Inbound انتخاب‌شده را با یک حساب آزمایشی بررسی کنید. ربات پیش از نوشتن اطلاعات، بررسی‌های اولیه از جمله میزبان اتصال و PSK مربوط به L2TP را انجام می‌دهد. اگر نتیجه عملیات نوشتن مبهم باشد، عملیات برای بررسی دستی قفل می‌شود تا اکانت تکراری ساخته نشود.

## به‌روزرسانی

در سرور و با دسترسی root:

```bash
cd /opt/aminui-sales-bot
sudo bash update.sh
```

اسکریپت به‌روزرسانی پیش از تغییرات از سورس، فایل `.env` و دیتابیس پیش‌فرض SQLite نسخه پشتیبان تهیه می‌کند؛ سپس وابستگی‌ها را نصب، کد را کامپایل و تست‌های واحد را اجرا می‌کند. فقط اگر سرویس پیش از آپدیت فعال بوده باشد، پس از موفقیت تست‌ها آن را مجدداً راه‌اندازی می‌کند؛ اگر سرویس از قبل متوقف بوده باشد، آن را خودکار روشن نمی‌کند.

اگر نصب شما در مسیر دیگری انجام شده، ابتدا وارد همان مسیر نصب شوید و سپس `update.sh` را اجرا کنید.

## امنیت و پشتیبان‌گیری

- هرگز فایل `.env`، نسخه‌های پشتیبان `.env.*`، فایل SQLite یا اطلاعات ورود پنل را در GitHub قرار ندهید.
- از فایل `.env` و دیتابیس SQLite با هم و در مکانی امن و جدا از GitHub نسخه پشتیبان بگیرید.
- مقدار `APP_ENCRYPTION_KEY` را نگه دارید؛ بدون آن اطلاعات رمزنگاری‌شده قابل بازیابی نیستند.
- بررسی گواهی TLS اجباری است؛ آن را غیرفعال نکنید.
- برای هر توکن ربات تلگرام فقط یک نمونه polling اجرا کنید تا از تداخل دریافت پیام‌ها جلوگیری شود.

## سازگاری API پنل

کلاینت ربات برای دریافت فهرست و جزئیات Inboundها، افزودن/ویرایش/حذف کلاینت‌ها و دریافت پروفایل‌های OpenVPN از endpointهای VPN-UI استفاده می‌کند. نسخه‌ها و فورک‌های مختلف VPN-UI ممکن است تفاوت داشته باشند. موفقیت تست‌های محلی به‌تنهایی تضمین نمی‌کند که تمام endpointهای نوشتن در فورک پنل شما کار کنند؛ پیش از فروش اکانت، نسخه دقیق پنل را آزمایش کنید.
