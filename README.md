# ربات فروش VPN-UI در تلگرام

ربات فروش و مدیریت اکانت VPN متصل به یک پنل VPN-UI؛ با منوی مشتری، پنل گرافیکی مدیریت، ثبت پرداخت کارت‌به‌کارت و ساخت و مدیریت حساب‌ها.

- 🇬🇧 [English](README.en.md)

## امکانات اصلی

- منوی مشتری فارسی و منوی گرافیکی مدیر در تلگرام
- پلن ثابت و پلن حجمی با محاسبه قیمت بر اساس حجم، قیمت هر گیگ در ماه و مدت اعتبار
- انتخاب نام کاربری توسط مشتری و جلوگیری از نام تکراری
- پرداخت کارت‌به‌کارت با ارسال رسید و تأیید یا رد دستی مدیر
- ساخت اکانت VLESS و L2TP و دریافت PSK از تنظیمات Inbound انتخاب‌شده
- تحویل فایل پروفایل OpenVPN در نسخه‌های سازگار پنل
- تست رایگان VLESS یک‌بار مصرف با حجم ۱ گیگ و اعتبار ۲۴ ساعت
- تمدید، مشاهده مصرف، فعال‌سازی، غیرفعال‌سازی و حذف اکانت
- پشتیبانی، پیام همگانی و پشتیبان‌گیری از دیتابیس
- رمزنگاری اطلاعات حساس ذخیره‌شده با Fernet

این نسخه به یک نمونه پنل VPN-UI متصل می‌شود و مدیریت چند پنل را انجام نمی‌دهد. ساخت اکانت WireGuard و OpenConnect در این نسخه پیاده‌سازی نشده است.

## نصب سریع

```bash
git clone https://github.com/amiinnoriizade-lang/aminui-sales-bot.git
cd aminui-sales-bot
sudo bash install.sh
```

نصاب اطلاعات اتصال تلگرام و پنل را دریافت می‌کند. اطلاعات محرمانه در فایل `.env` با دسترسی محدود ذخیره می‌شوند. کلید رمزنگاری فقط یک‌بار ساخته می‌شود؛ حتماً از آن نسخه پشتیبان امن بگیر و پس از ذخیره اکانت‌ها آن را تغییر نده.

مسیر پیش‌فرض نصب `/opt/vpnui-sales-bot` و نام سرویس `vpnui-sales-bot.service` است. برای جزئیات نصب، تنظیم اولیه، به‌روزرسانی و امنیت، زبان موردنظرت را از بالای صفحه انتخاب کن.

## نکته امنیتی

فایل‌های `.env`، دیتابیس و اطلاعات ورود پنل را در GitHub منتشر نکن. برای هر توکن ربات تلگرام فقط یک نمونه polling اجرا کن.
